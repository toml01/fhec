# spec/

Normative specification of the `.fsol` dialect and the `fhec` transpiler's observable behavior (RFC-2119 language). Diagnostics cite section numbers, so section numbering is stable within a spec version.

Versioning: the spec version (`spec.md` header) is independent of the tool version; it freezes at 1.0 alongside the fhec 1.0 release, after external review.
